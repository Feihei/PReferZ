# v0.5.0

> MCP 单一天选窗口（多实例自动让位/认领）+ 左侧栏全局开关与统一 hover；内置帮助文档双语；
> egui 0.37 升级让文字密集画布的缩放明显更顺滑。

**下载**：Windows x64 / Linux x64 / Linux aarch64 / macOS universal（各平台 zip 或 tar.gz），
随附 SHA256SUMS。

---

## 亮点

- **MCP 单一天选窗口**：多个 PReferZ 窗口同时打开时，`preferz --mcp` 只连接一个确定的窗口。
  窗口启动不再抢占现有控制权；控制方退出后，其余窗口 1 秒内自动接手；也可在左侧栏
  MCP 开关手动切换控制权（绿点 = 正在被 agent 控制 / 灰点 = 待命 / 空心 = 关闭）。
- **左侧栏全局开关 + HUD 瘦身**：语言 / 明暗 / 默认风格 / MCP 四个开关从画布左下 HUD
  移入左侧栏、帮助按钮之上；左下只剩缩放胶囊（− / 百分比输入 / +），画布更干净。
- **统一 hover 反馈**：工具按钮、帮助按钮、四个全局开关、调色板色块、填充样式、
  箭头选择器、右侧属性面板——悬停一律是底色高亮，不再有各不相同的白边 / 灰块。
- **内置帮助文档双语**：英文界面点帮助打开英文版（与中文版同布局逐项对应），
  不再出现英文界面弹中文内容。
- **egui 0.37 升级**：文字密集画布（如 61 项的帮助文档）滚轮缩放平均帧耗时
  约 7.4 ms → 1.8 ms（字号量化，连续多帧复用排版缓存）；界面图标恢复单色 emoji；
  复制 / 粘贴行为不变。

## 改进

- MCP 截图链路迁移到 egui 0.37 的一次性截图回调：同一请求只回一帧，3 秒超时兜底保留。
- 帮助文档补充 MCP 开关位置与三态点含义。

## 修复

- Fix 多窗口下 MCP 控制权被后启动窗口无条件抢占（原握手文件 last-writer-wins）；
  崩溃残留的陈旧握手文件会被自动清理，待命窗口随即认领。

## 内部

- egui / eframe 0.36.2 → 0.37.0；源码构建的最低 Rust 版本抬到 1.95。
- 清理 22 处 0.37 弃用 API；eframe 显式开启 clipboard / system_fonts /
  monochrome_emoji_fonts feature。
- 全量测试 423 项，`cargo fmt --check` / `clippy -D warnings` 零告警。

## 破坏性变更

- 无（发布为预编译二进制；仅从源码构建需要 Rust ≥ 1.95）。

## 已知

- 文字极多的大画布缩放仍受 egui 0.37 文字重排成本限制（已用字号量化缓解），
  超大文档的手感可能不如小文档顺滑。

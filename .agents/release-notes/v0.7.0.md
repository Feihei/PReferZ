# v0.7.0

> macOS 成为一等平台：⌘ 快捷键、正式 Dock 图标与 universal 安装包一次补齐；触控板捏合缩放与双指平移；元素颜色改为基色存储，切换明暗主题不再让黑色元素或文字消失；大画布手绘风最高提速 4 倍。
>
> PReferZ is now a first-class macOS app — ⌘ shortcuts, a proper Dock icon, a universal bundle — plus trackpad pinch/pan, theme-safe colors, and up to 4× faster hand-drawn rendering.

**下载**：Windows x64 / Linux x64 / Linux aarch64 / macOS universal（zip 或 tar.gz）。

---

## 亮点

- **macOS 键盘终于对了**：主修饰键改为平台主键（macOS 用 ⌘，其它平台仍是 Ctrl）——撤销、保存、复制粘贴等**所有**快捷键此前在 macOS 上全部失效，现已修复。
- **⌘Q 退出 / ⌘W 关闭窗口**：Windows / Linux 对应 Ctrl+Q / Ctrl+W（此前两组键都未占用）；打字过程中也能退出，未保存的文档仍会先弹保存提示。
- **快捷键提示不再教错**：macOS 上显示 `⌘⇧S` 这类系统符号，而不是按不出来效果的 `Ctrl+Shift+S`。
- **macOS 安装包与图标**：Dock 与访达显示正式图标；下载的是 Intel 与 Apple Silicon 通用的 **PReferZ.app**。
- **触控板手势**：双指捏合缩放、双指滑动平移。按**设备**判断而非按平台，所以 macOS 接鼠标时仍是滚轮缩放，其它平台行为与之前完全一致。
- **切换主题不再丢元素**：元素颜色改为「基色存储 + 绘制期滤镜」（与 Excalidraw 同语义）——浅色下画的黑色图形切到深色后依然清晰，反之亦然，不再需要手动改色；旧工程首次打开会自动判定创作用色并转回基色，导出 PNG / SVG 也跟随当前主题的底色与元素色。
- **大画布手绘风提速**：图形在屏幕上缩到 24 像素以下时自动回落为规整描边（这个尺寸下抖动本就看不出来），用于「缩到全景看上千个元素」的场景。实测 2000 个元素 41 → 10 ms、5000 个 84 → 29 ms、10000 个 157 → 62 ms 每帧。

## 改进

- 内置帮助新增完整英文版，与中文版由同一份版式生成，不再各自漂移。
- 帮助页去掉浅色纸张底版——暗色主题下整页随主题翻转，深浅两套主题都清晰。
- 帮助里的快捷键清单同步到当前版本：macOS 上 Ctrl 即 Cmd、Alt 即 Option，双指平移与捏合缩放，Backspace 也能删除，退出与关闭窗口快捷键。

## 修复

- Fix 另存为把 `Board.PRZ` 写成 `Board.PRZ.prz`（macOS / Windows 文件系统大小写不敏感），导出后缀同修。
- Fix Git Bash 下配置文件被写到盘符根目录（`HOME=/c/Users/…` 被按 `\c\Users\…` 解析），同时统一各处的 home 目录优先级。
- Fix 从已打开窗口新建窗口时，macOS 上新窗口没有 Dock 图标、也不自动置前。
- Fix 日志从未真正输出：现在默认写入 `~/.preferz/preferz.log`（超过 1 MiB 自动轮转），设置 `RUST_LOG` 则仍输出到终端；反馈问题时可以附上这个文件。

## 内部

- macOS 发布产物从裸二进制改为 `PReferZ.app` 通用包（lipo 合并 + 最小 Info.plist + ad-hoc 签名）。
- 新增画布压测基准（`cargo test --release -p preferz --lib perf_stress -- --ignored`），为渲染层选型与后续优化提供可复现的帧耗时数据。

## 破坏性变更

- macOS 产物由裸 `preferz` 二进制改为 `PReferZ.app` bundle：命令行用法变为 `PReferZ.app/Contents/MacOS/preferz`，`--headless` / `--mcp` 等参数不变。Windows 与 Linux 产物形态不变。

## macOS 安装（首次运行需放行）

1. 下载 `preferz-0.7.0-macos-universal.tar.gz`，双击解压得到 **PReferZ.app**（Intel 与 Apple Silicon 通用，无需选版本）
2. 双击 PReferZ.app，系统提示"无法验证开发者"→ 点「完成」
3. 打开 **系统设置 → 隐私与安全性**，滚动到最底部，点「仍要打开」，输入密码或 Touch ID 确认
4. 之后直接双击即可启动；升级新版本后需重复第 2~3 步

**English**

1. Download `preferz-0.7.0-macos-universal.tar.gz` and double-click to extract **PReferZ.app** (universal build, Intel & Apple Silicon)
2. Double-click PReferZ.app — macOS says "cannot verify the developer" → click "Done"
3. Open **System Settings → Privacy & Security**, scroll to the bottom, click **"Open Anyway"**, confirm with password / Touch ID
4. Subsequent launches open normally; repeat steps 2–3 after each upgrade

> 注意：macOS 15 (Sequoia) 起，右键"打开"不再能放行未公证应用，必须走系统设置里的「仍要打开」。本应用为个人开源项目，未购买开发者证书公证，此步骤无法省略。
> Note: since macOS 15 (Sequoia), right-click → "Open" no longer bypasses Gatekeeper for unnotarized apps — use "Open Anyway" in System Settings. This app is not notarized (no paid developer certificate), so this step cannot be skipped.

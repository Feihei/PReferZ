> MCP 控制权切换改为「先确认再接管」、新窗口启动默认关闭 MCP；端点吸附在复制与
> 整体移动后不再丢失；elbow 连线消除跳变与回折。

**下载**：Windows x64 / Linux x64 / Linux aarch64 / macOS universal（各平台 zip 或 tar.gz），
随附 SHA256SUMS。

---

## 亮点

- **MCP 接管先问再切**：从正在被 agent 控制的窗口夺走控制权，必须由你在侧栏徽标上
  主动开启并确认（弹框会提示「原窗口转待命，进行中的调用可能中断」）；
  控制权自动认领 / 被接管都有提示，不再无声易手。
- **新窗口启动默认关闭 MCP**：打开新窗口不再打断已在被操作的旧窗口，也不会弹窗；
  需要时点侧栏 MCP 徽标手动开启。
- **端点吸附不再丢失**：复制 / 粘贴 / Ctrl+拖动复制时，副本连线自动改绑到副本上的
  图形；把线与它的绑定目标一起拖动、或整组移动，吸附关系同样保留。
- **连线更稳定**：修复 elbow 在两端图形靠近时跳变、180° 回折与多余线段的问题；
  线条本身不再被当作吸附目标，历史存档里的脏绑定会在打开时自动清理。

## 改进

- 回车编辑已有文字时默认全选，直接输入即整段替换（新建空文字不受影响）。

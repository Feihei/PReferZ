# v0.3.0

> 对齐 Excalidraw 的第二个打磨批次：elbow 直角连线自动避障、mermaid 图更整洁、
> 手绘风填充补全，新增元素超链接与内置帮助文档。

**下载**：Windows x64 / Linux x64 / Linux aarch64 / macOS universal（各平台 zip 或 tar.gz），
随附 SHA256SUMS。

---

## 亮点

- **elbow 连线自动避障**：两端绑定图形的直角连线自动绕开遮挡元素，拖动节点实时重路由
  （移植 Excalidraw elbowArrow 算法：非均匀网格 + 转弯罚，最少转弯优先）。
- **elbow 中间段固定**：选中连线后每个中间段带拖拽手柄——拖动即固定该段，其余段自动
  绕行重算；再拖已固定段改位。
- **elbow 取向稳定**：连线走向改由端点锚定的图形边缘法线决定，拖动绑定图形跨过对角线
  不再 90° 跳变；无绑定端有 1.3× 滞回稳定带。
- **mermaid 图布局质量**：同层节点重心排序减少交叉；连线默认直角 elbow，节点拖动自动
  重路由。
- **手绘风填充补全**：填充样式新增**之字线**与**圆点**两档（rough.js 自移植，确定性
  随机）；椭圆收笔「画过起点再收」，更接近 rough.js 观感。
- **元素超链接**：给任意元素挂 web 链接或本地 `.prz` 文件——悬停显示右上角 ↗ 徽标点击
  打开（本地文件开新窗口）；`Ctrl+K` 编辑，props 面板与右键菜单均可增删。
- **内置帮助文档**：左下 HUD `?` 按钮打开独立帮助实例（help.prz 内嵌随包分发，沙箱
  语义：改动不落盘），内容随版本同步更新。
- **全选套件**：`Ctrl+A` 全选、`Ctrl+Shift+A` 取消全选（绑定文字随容器联动，不单独入选）。

## 改进

- 属性面板：跨类型多选时显示**属性级交集**（颜色 / 线宽）批量编辑，一条 undo；
  面板宽度钳制、高度撑满窗口、内容超高时竖向滚动。
- 属性面板数字项支持按住左右拖连续调值（Blender 式），拖拽速度按字段量程配速。
- 缩放 HUD 移至左下角（不再被撑满的侧栏遮挡），与语言 / 主题 / 默认风格开关合并为单块弹层。
- 欢迎页与内置帮助文档文案精简。

## 修复

- Fix 文字工具单击创建的编辑框被点击释放沿误关，现在单击即可进入编辑（`e06e830`）
- Fix 右侧栏高度从未真正撑满窗口（anchored Area 自引用冻结），并修宽度吃满的回归（`9e2e083` / `8f24949`）
- Fix 点选已吸附连线时高亮框残留、端点绑定被静默清空导致路径翻转跳变（`0b7dd0f`）
- Fix 链接输入框打字被逐帧清空、无法编辑（`052f608`）
- Fix zigzag 填充长线上两笔重叠看不出锯齿，重写为连续锯齿折线；dots 行距减半变密（`b243a61`）

## 内部

- core 新增 `routing.rs`（headless 纯函数）：A* 网格路由与固定段缝合独立于 egui 可测。
- `.prz` 向后兼容：`link` / `elbow_axis` / `fixed_segments` 等新字段 `serde(default)` 零迁移；
  items 表 `link` 列自动 `ALTER TABLE` 就地迁移，`USER_VERSION` 不变。
